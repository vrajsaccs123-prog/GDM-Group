Ghanshyam Dall Mill
===================

Company site for Ghanshyam Dall Mill, Indore. The daily rate list is read live from the Google Sheet. Edit the sheet, then refresh the website. A new deploy is not required for a price change.

Sheet columns:

1. Product
2. Brand
3. Rate, with the date written in the column heading (for example `18th November 2026`)

A row with only a name, such as `CHANA DAL`, starts a section. A product row with an empty rate, followed by `50kg` or `30kg` rows, is one product in more than one packing.

The sheet must stay shared so anyone with the link can view it.

# Ghanshyam Dal Mill

Daily rate list for Ghanshyam Dal Mill. The site reads the mill Google Sheet live. Edit the sheet, then refresh. A new deploy is not required for a price change.

Sheet: https://docs.google.com/spreadsheets/d/1j3XpKOZo06tEyxmwedajKFC8LSVe9mkZuf_z6vw8vvs/edit

Columns:

1. Product
2. Brand
3. One column per date. The heading is the date, for example `18th November 2026`.

The newest date is today's list. Older date columns stay on Rate History. A change from the previous date shows beside the rate.

A row with only a name, such as `CHANA DAL`, starts a section. A product row with an empty rate, followed by `50kg` or `30kg` rows, is one product in more than one packing.

The sheet must stay shared so anyone with the link can view it.
